# Game Icons Font

This font is a collection of icons that I use in game development. It is not a dingbat font.

It includes a variety of symbols and graphics that I want to use in my games,
like: dice, cards, keyword ligatures, and stuff.

Most of these icons came from the [Game Icons](https://game-icons.net/) website, which is a great resource for free game-related icons.
The base font I use is [SourceSans3-Regular](https://github.com/adobe-fonts/source-sans/), which is a free font from Adobe licensed under the SIL Open Font License.

Yet the rest of them are icons I made myself using Adobe Illustrator; this might make your game look like mine--which might not be what you want.
The good news is that you can customize the font to your liking, and I will explain how to do that below.


## Licensing

Please note that the font is licensed under the [SIL Open Font License](https://scripts.sil.org/OFL), which means you can use it in your games for free, even commercially. You can also modify it and redistribute it, as long as you follow the terms of the license.


## Customization

I created a font, ligature, and icon tooling that allows you to customize the font to your liking. You can change the icons, add new ones, or even create your own ligatures.

This tool is written in Python and is located at: https://github.com/mistralCeleste/LigatureIconGenerator.

Directions on how to use the tool and customize the font are included in the repository.
